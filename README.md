# 展諒課業 — 小孩版今日清單

iPad 打開就看到「今天要做什麼」，勾完有回饋。計畫資料放在 `data/` 的四個 CSV，改完推上 `main`，iPad 下次打開自動反映。
單檔 `index.html`，無 build step，部署在 GitHub Pages：https://ianyclin.github.io/chanliang/

- 測試某一天：網址加 `?date=2026-10-26`
- 勾選紀錄存在 iPad 本機（localStorage）。想寫回 Google Sheet 再看第三節。

## 一、資料檔（`data/` 四個 CSV）

預設模式 `READ_MODE: 'repo'` 直接讀這四個檔。想改用 Google Sheet 當資料來源，開一份 Sheet 叫「展諒課業」，用這四個 CSV「檔案 → 匯入 → 插入新工作表」建四個分頁，再看第二節。

### 1. `進度母表`（有明確目標日的項目）
| 科目 | 項目 | 子項 | 目標日 | 狀態 | 備註 |
|---|---|---|---|---|---|
| 數學 | 評量 | 2-1 | 2026-10-22 | 已排 | |
| 社會 | 習作 | 第12頁 | 2026-10-26 | 已排 | |
| 自然 | 習作 | 第8頁 | | 未排 | |

- 目標日 = 今天 → 出現在「今天要做的」；目標日 < 今天且沒勾 → 「之前還沒做完的」。
- 沒填目標日的只算進「各科進度」的總數，不會出現在清單。
- 狀態填「完成」等於家長幫他勾掉。
- 日期格式 `2026-10-22`、`2026/10/22`、`10/22` 都可以。

### 2. `週規則`（每週固定的）
| 星期 | 科目 | 規則 | 可補做 |
|---|---|---|---|
| 六 | 國語 | 評量新單元上半＋預習下一課 | 是 |
| 日 | 數學 | 奧數 | 是 |
| 三六日 | 小提琴 | 練琴 20 分鐘 | 否 |
| 每天 | 英文 | 聽英文 10 分鐘 | 否 |

- 星期可以寫「六」「三六日」「一二三四五」「每天」「平日」「週末」。
- 規則用「＋」分開會變成多個勾選項。
- 可補做 = 否：昨天沒勾也不會跑到「之前還沒做完的」（例行項目用）。

### 3. `大事記`
| 日期 | 事件 | 類型 | 科目（選填） |
|---|---|---|---|
| 2026-10-27 | 社會小考 第一單元 | 考試 | 社會 |
| 2026-11-01 | 學校運動會 | 活動 | |

- 類型含「考」的，頁面最上面會倒數最近一筆，考前 2 天自動出現「✏️ 複習：…」。

### 4. `完成紀錄`
由 Apps Script 自動寫入，不用手動填（第一次 Apps Script 會自己建）。
想「取消」小孩的勾，直接刪那一列即可。

## 二、（選用）改用 Google Sheet 當資料來源（二選一）

**方式 A（推薦）**：Sheet 右上「共用」→ 一般存取權改成「知道連結的任何人：檢視者」。
把網址 `https://docs.google.com/spreadsheets/d/【這一串】/edit` 中間那串貼到 `index.html` 的 `CONFIG.SHEET_ID`。

**方式 B**：檔案 → 分享 → 發布到網路 → 整份文件。把發布網址 `/d/e/【2PACX-…】/` 那串貼到 `CONFIG.PUBLISHED_ID`，
`READ_MODE` 改成 `'published'`，並把四個分頁的 gid（網址 `#gid=數字`）填進 `CONFIG.GIDS`。
（Google 對發布的 CSV 有約 5 分鐘快取。）

## 三、（選用）完成紀錄寫回 Google Sheet（Apps Script）

1. Sheet → 擴充功能 → Apps Script，把 `apps-script/Code.gs` 內容整個貼進去，存檔。
2. 部署 → 新增部署作業 → 網頁應用程式：執行身分「我」、存取權「任何人」。第一次會要求授權。
3. 把 `/exec` 結尾的網址貼到 `CONFIG.SCRIPT_URL`。
4. 瀏覽器打開那個網址看到 `{"ok":true,...}` 就對了。

沒填 `SCRIPT_URL` 也能用，只是勾選只存在那台 iPad。離線時勾的會先存本機，連上網再補送。

## 四、放上 GitHub Pages、加到 iPad 主畫面

1. GitHub repo → Settings → Pages → Source 選「Deploy from a branch」→ `main` / root。
2. iPad Safari 打開網址 → 分享 → 「加入主畫面」，就會全螢幕開啟。
3. **沒有用 Service Worker**，所以改版不會卡舊版。改完 `index.html` 記得順手改 `CONFIG.VERSION`，頁面最底下會顯示版本號，確認 iPad 拿到新版（GitHub Pages 最多延遲約 10 分鐘）。

## 網頁怎麼算「今天要做的」

今天要做的 = 週規則展開到今天 ＋ 進度母表目標日＝今天 ＋ 大事記考前 2 天的複習項。
之前還沒做完的 = 前 3 天（`BACKLOG_DAYS`）週規則沒勾的（可補做≠否）＋ 母表目標日已過沒勾的。
全部勾完會有慶祝畫面（每天一次）。
